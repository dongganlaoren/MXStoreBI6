| 类别                 | 字段名称                                                     | 计算公式                                                     | 说明                                                         |
| -------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 收银机小票信息录入   | 现金收入                                                     |                                                              | POS机小票里显示的收入的总现金金额                            |
| 电子支付收入         |                                                              | POS机小票里显示的收入的电子支付的总金额                      |                                                              |
| 外卖收入             |                                                              | POS机小票里显示的店内外卖收入总金额                          |                                                              |
| 代金券使用金额       |                                                              | POS机小票里显示的代金券总金额                                |                                                              |
| 店铺理论营业额（T0） | 店铺理论营业额=现金收入+电子支付收入+外卖收入+POS机小票里显示的代金券总金额 | POS机小票打印的销售情况认为是理论营业情况                    |                                                              |
| 第三方外卖平台       | 第三方外卖平台收入（T1）                                     |                                                              | 店内人员录入各个已开通第三方外卖平台店铺的外卖收入总额       |
| 理论营收总金额       | 理论营收（T2）                                               | 理论营收（T2）=店铺理论营业额（T0）+第三方外卖平台收入（T1）-POS机小票里显示的代金券总金额-银行存款金额 | 去除代金券之后，理论上账户应该收入的总额                     |
| 实际入账             | 电子支付实际入账金额                                         |                                                              | 店内人员根据实际情况录入到系统（为实际到账的电子支付部分）   |
| 银行存款金额         |                                                              | 实际存入总账户的现金金额（为实际到账的现金部分）。           |                                                              |
| 银行存款手续费       |                                                              | 店内人员根据实际情况录入到系统                               |                                                              |
| 误差计算             | 总误差                                                       | 总误差=电子支付实际入账金额+银行存款金额+银行存款手续费-POS机小票里显示的收入的电子支付的总金额-POS机小票里显示的收入的总现金金额 | 总误差，去除银行手续费之后的金额，需要展示给审核人员；计算结果如果是负数，说明实际收入小于理论收入，到达一定额度，需要店内赔付给公司总部 |
| 实际总营业额         | 实际总营业额                                                 | 实际总营业额=第三方外卖平台收入（T1）+外卖收入+电子支付实际入账金额+银行存款金额 | 实际到账的所有收入，不包括代金券和银行手续费                 |
