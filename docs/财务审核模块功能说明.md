
## 店内人员（分店长及店员）操作内容

1. 填写小票的现金收入（C）—— cash_income。
2. 填写小票的POS电子支付收入（P）—— pos_income。
3. 填写POS系统中记录的外卖收入（D）—— day_pass_income。
4. 填写小票的代金券使用金额（R）—— voucher_amount。
5. 系统自动计算：POS机记录的店内净收入（T）= C + P + D - R。
6. 店内人员将收到的现金部分存入银行（会产生手续费），并上传银行存款凭证。电子支付款项自动汇入公司账户，无需人工操作。
7. 汇报第三方外卖平台收入及上传相关凭证。
8. 分阶段录入数据，支持凭证图片上传，最终提交后不可修改。

## 财务审核内容（MVP极简模式）

1. 核对店员存入银行的现金部分是否到账，并计算与POS现金收入（C）的误差：
   - 现金实际误差 = POS现金收入（C）- 现金实际到账金额 - 银行存款手续费
2. 核对电子支付收入是否到账，并计算与POS电子支付收入（P）的误差：
   - 电子支付实际误差 = POS电子支付收入（P）- 电子支付实际到账金额
3. 系统自动计算总误差：
   - 总误差 = 现金实际误差 + 电子支付实际误差
4. 系统自动计算店铺单日实际净收入：
   - 单日净收入 = POS机记录的店内净收入（T）+ 第三方外卖平台收入 + 总误差
5. 财务可对每条日报进行审核，核对“实际到账金额”字段（该字段由店内人员填写），如核对不符，需线下与门店沟通确认原因，并根据最终商议结果由财务修改该字段值。系统自动记录“实际到账金额”字段的所有修改记录。审核时还可填写审核备注，并可查看历史凭证图片。
6. 审核流程仅包含两个状态：
   - “待审核”：日报提交后自动进入此状态，财务可核对和修改关键字段。
   - “已审核”：财务核对无误或修正后，点击“审核通过”即进入此状态，日报归档不可再编辑。
7. 支持按门店编号、日期筛选、分页查看所有日报，便于批量审核。
8. 所有审核和关键字段修改均记录操作日志，便于追溯。

## 系统自动化与安全性说明

- 所有金额计算均由系统自动完成，减少人工误差。
- 所有操作均有权限控制，店员仅能操作本店数据，财务/管理员可全局审核。
- 所有关键操作（上报、审核、归档）均记录操作日志，便于追溯。
- 上传的凭证图片统一存储于安全目录，前端展示路径自动适配。

## 典型业务流程

1. 店员分阶段录入营业数据，上传相关凭证，最终提交日报。
2. 财务人员登录系统，按门店/日期筛选待审核日报，逐条核对并填写审核结果。
3. 系统自动计算误差、净收入等关键指标，辅助财务决策。
4. 审核通过后日报归档，数据长期保存，支持后续查询与统计分析。
