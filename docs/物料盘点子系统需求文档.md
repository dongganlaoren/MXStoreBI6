# MXStoreBI6 仓库 - 库存盘点（inventory-stocktake）子系统 需求文档（V1.3）

**文档版本**：V1.3

**适用对象**：AI 编程机器人

**核心目标**：在 MXStoreBI6 仓库中新增独立的 `inventory-stocktake`（库存盘点）子系统模块，兼容现有技术栈和工程化规范，聚焦**库存盘点、货值计算、产品信息模板导入维护**核心能力。

## 一、 项目背景与约束

1. **技术栈约束**：基于 Python 开发，遵循 MXStoreBI6 现有技术栈

2. **工程化约束**：严格遵循仓库现有目录结构、代码规范、测试规范、部署运维规范

3. **兼容性约束**：新模块需独立成包，低耦合接入现有系统，不修改原有核心业务代码

4. **模块名称约束**：模块统一命名为 `inventory-stocktake`（库存盘点），所有相关目录、文件、配置均对齐该名称

5. 功能变更约束

   - 取消**所有导出功能**：包括报表导出、失败记录导出等
   - 取消**所有接口功能**：不提供 RESTful API，仅保留前端页面与后端服务的内部调用
   - 仅保留**产品信息模板导入**功能，取消其他数据导入方式
   - 产品信息中**预留产品图片字段**，非必填，暂不实现上传功能

   

6. **适配约束**：库存盘点前端页面需支持手机端适配，保证移动端操作流畅

## 二、 核心功能需求

### 2.1 功能模块 1：库存盘点

#### 核心目标

支持店铺录入物料库存数据（剩余整件数、剩余散件数），实现数据校验与保存，前端页面支持手机端适配。

#### 详细需求

1. **数据来源**：对接现有 `shop_info` 表获取店铺信息，支持多店铺切换

2. **录入字段**：物料编码、物料名称、规格、剩余整件数、剩余散件数

3. 数据校验

   - 剩余整件数、剩余散件数必须为非负整数
   - 物料编码必须在物料信息表中存在

   

4. 操作功能

   - 单条物料库存保存
   - 批量物料库存保存
   - 库存数据重置（清空当前录入数据）

   

5. **数据存储**：库存数据存入 `mx_inventory_check` 表，记录店铺 ID、盘点日期、操作员、操作时间

6. 手机端适配要求

   - 页面布局：采用响应式布局，适配手机端屏幕（320px-768px），无横向滚动条
   - 操作控件：按钮、输入框放大优化，适配手机触控操作（按钮高度不低于 44px，输入框间距不小于 10px）
   - 交互优化：支持移动端常见操作（下拉刷新库存列表、上拉加载更多物料、点击输入框弹出数字键盘）
   - 样式适配：表格自适应折叠，核心字段（物料名称、库存数量）优先展示，非核心字段可折叠展开
   - 性能要求：手机端页面加载时间不超过 3 秒，操作响应时间不超过 1 秒，无卡顿闪退

   

### 2.2 功能模块 2：货值计算

#### 核心目标

根据库存数据自动计算物料货值，支持汇总统计，无导出功能。

#### 详细需求

1. 计算逻辑

   - 单物料货值 = 剩余整件数 × 每件单价 + 剩余散件数 × 每组单价
   - 类别货值 = 该类别下所有物料货值之和
   - 总货值 = 所有类别货值之和

   

2. **数据来源**：从 `mx_material_info` 表获取物料单价数据，从 `mx_inventory_check` 表获取库存数据

3. **数据展示**：计算结果直接在前端页面展示，支持按物料、类别筛选查看

4. **缓存策略**：计算结果支持缓存，重复查询时直接返回缓存数据，提升效率

5. **异常处理**：物料单价为空时，抛出明确异常并记录日志，前端页面给出提示

### 2.3 功能模块 3：产品信息模板导入维护

#### 核心目标

仅支持通过 Excel 模板导入实现产品信息的新增与更新，预留产品图片字段，无其他数据维护方式。

#### 详细需求

1. 物料信息字段（新增产品图片字段）

   | 字段名           | 数据类型 | 是否必填 | 备注                                         |
   | :--------------- | :------- | :------- | :------------------------------------------- |
   | 操作类型         | 下拉选择 | 是       | 仅可选：新增 / 更新                          |
   | 物料编码         | 文本     | 是       | 新增填唯一编码，更新填已有编码（匹配关键字） |
   | 中文名称         | 文本     | 是       | -                                            |
   | 泰文名称         | 文本     | 否       | -                                            |
   | 规格型号         | 文本     | 是       | -                                            |
   | 每组数量         | 整数     | 是       | 非负                                         |
   | 每件单价（泰铢） | 小数     | 是       | 保留 2 位小数                                |
   | 每组单价（泰铢） | 小数     | 是       | 保留 2 位小数                                |
   | 物料类别         | 下拉     | 是       | 可维护下拉框                                 |
   | 安全库存         | 整数     | 否       | 非负                                         |
   | 状态             | 下拉选择 | 是       | 仅可选：启用 / 禁用                          |
   | **产品图片**     | 文本     | 否       | 预留字段，暂存图片路径 / 标识，无上传功能    |
   | 备注             | 文本     | 否       | -                                            |

   

2. 模板导入规则

   - 仅支持 `inventory_stocktake_template.xlsx` 标准模板导入，无其他导入方式
   - 支持两种导入模式：「新增模式」「更新模式」，通过「操作类型」字段区分
   - 新增模式：物料编码不存在则新增，存在则抛出重复异常并跳过
   - 更新模式：以物料编码匹配现有数据，仅更新模板中非空字段，空字段不覆盖原有数据
   - 产品图片字段为预留字段，仅存储文本信息，暂不实现图片上传、预览功能

   

3. 导入校验

   - 校验模板格式是否正确（表头字段、工作表名称是否匹配）
   - 校验必填字段是否为空、数值字段是否合法（非负）
   - 校验操作类型、状态是否为下拉选项内的值
   - 更新模式下校验物料编码是否存在

   

4. 导入反馈

   - 导入结果直接在前端页面展示，包含成功条数、失败条数、失败原因
   - 取消失败记录导出功能，失败原因支持页面复制
   - 采用数据库事务，保证单条物料数据的原子性，支持部分导入

   

### 2.4 功能模块 4：报表功能（功能裁剪）

#### 核心目标

仅在前端页面展示库存相关数据，取消报表生成与导出功能。

#### 详细需求

1. 展示内容

   - 库存现状：当前物料库存数量、货值明细
   - 货值分析：按类别展示货值占比（前端页面用图表展示）
   - 盘点历史：展示指定时间段内的盘点记录列表

   

2. **筛选条件**：支持按店铺、日期范围、物料类别筛选数据

3. **功能裁剪**：取消报表生成、归档、导出功能，所有数据仅在页面展示
