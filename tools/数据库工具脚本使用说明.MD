## 脚本功能

1. **备份数据库**
   - 可备份任意数据库，包括生产库 `MXStoreBI_Production`
   - 自动生成 `.sql.gz` 文件
   - 自动清理过期备份（默认保留 7 天）
   - 日志记录备份操作
2. **恢复数据库**
   - 交互选择历史备份文件
   - 可以恢复到任意数据库，禁止覆盖生产库
   - 自动检测目标数据库是否存在，存在则清空，否则创建
   - 恢复完成后校验表数量
   - 日志记录恢复操作
3. **删除数据库**
   - 可删除非生产数据库
   - 删除前二次确认
   - 日志记录删除操作
4. **日志管理**
   - 查看最近 50 条操作日志
   - 日志文件统一保存 `/var/log/db_tool.log`
5. **自动/手动清理过期备份**
   - 默认保留 7 天，可手动清理
6. **安全保护**
   - 生产数据库禁止删除或恢复覆盖
   - 提示信息彩色化，操作可控

## 使用说明

1. 给脚本可执行权限：

```
scp /Users/renweimin/PycharmProjects/FlaskProject/Git/0723007/tools/db_tool.sh alibaba:/root/
chmod +x db_tool.sh
```

1. 执行脚本：

```
./db_tool.sh
```

1. 选择菜单操作：

   ```
   1) 备份数据库
   2) 恢复数据库
   3) 查看日志
   4) 清理过期备份
   5) 删除数据库
   6) 退出
   ```

2. 日志文件路径：`/var/log/db_tool.log`

3. 备份文件目录：`/var/backups/mysql`

4. 默认保留备份天数：7 天，可修改 `RETENTION_DAYS`
