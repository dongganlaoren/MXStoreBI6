# 蜜雪IB系统

这是一个基于 Flask 的 BI 系统应用。

## 快速开始

### 自动运行（推荐）

使用提供的脚本自动激活虚拟环境并运行应用：

```bash
./run_flask.sh
```

脚本会自动：
1. 检查虚拟环境是否存在
2. 如果虚拟环境未激活，自动激活它
3. 运行 Flask 应用在端口 5001

### 手动运行

如果需要手动运行：

```bash
# 激活虚拟环境
source venv/bin/activate

# 运行应用
python run.py
```

## 功能特性

- 用户认证和权限管理
- 财务报销系统
- 考勤打卡功能
- 店铺管理
- 报表中心
- 多语言支持（中文、泰文、英文）

## 访问应用

应用启动后，访问：
- http://127.0.0.1:5001 (本地访问)
- http://127.0.0.1:5001/reimbursement/?lang=zh (财务报销页面)

## 开发环境

- Python 3.13.4
- Flask 3.1.2
- SQLite 数据库
- Bootstrap 5 前端框架

## 项目结构

```
MXStoreBI6/
├── app/                    # 应用主目录
│   ├── templates/         # HTML 模板
│   ├── static/            # 静态文件
│   ├── models/            # 数据模型
│   ├── views/             # 视图函数
│   └── utils/             # 工具函数
├── venv/                  # 虚拟环境
├── run.py                 # 应用入口
├── run_flask.sh          # 自动运行脚本
└── requirements.txt      # 依赖包列表
```

## 注意事项

- 确保虚拟环境已正确创建
- 首次运行前需要初始化数据库
- 开发模式下会自动重启应用
