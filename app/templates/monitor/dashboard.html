运维CLI命令参考
监控系统管理
flask init-monitoring 初始化监控系统
flask test-monitoring 测试监控系统功能
flask cleanup-monitoring-data 清理过期监控数据
flask logs-tail 实时查看系统日志文件
数据库管理
flask db upgrade 应用数据库迁移
flask db migrate -m "message" 创建数据库迁移文件
flask db current 查看当前数据库版本
应用管理
python run.py ���动开发服务器
gunicorn -w 4 -b 0.0.0.0:5000 run:app 生产环境启动（4个工作进程）
flask fake-data 生成测试数据
监控状态查询
ps aux | grep python 查看Python进程状态
df -h 查看磁盘使用情况
free -h 查看内存使用情况
重要提示
  • 执行CLI命令前请确保在项目根目录：cd /path/to/project
  • 生产环境操作前建议先备份数据库
  • 监控数据会根据配置自动清理，默认保留30天日志，7天指标
  • 如需修改监控配置，请编辑 .env 文件中的 MONITORING_* 参数
故障排查
  • 应用无法启动：检查 app.log 文件查看错误信息
  • 数据库连接失败：确认 .env 中的 DATABASE_URL 配置
  • 监控数据异常：运行 flask test-monitoring 测试各组件状态
  • 内存/磁盘告警：及时清理日志文件和临时文件
